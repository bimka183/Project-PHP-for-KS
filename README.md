Сайт с процессами, запущенные на сервере, с возможностью сортировки. Сделано на скорую руку, как задачка из ВУЗа. 

CPU Usage - показывает потребление ЦП из диспетчера задач. Погрешность есть, из-за того, что процессы обновляются редко, но она не столь велика.

PID - ID самого процесса.

Owner - юзер, на котором запущен процесс. На данный момент не работает.

Conmmand - к какой программе относится процесс
